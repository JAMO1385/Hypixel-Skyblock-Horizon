# Horizon Hypixel Companion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a usable Rust .hnmod and source for Hypixel lobby and SkyBlock.
**Architecture:** Dependency-free core crate with bounded state machines; mixin packet adapter and HUD/settings/command helpers in Horizon.
**Tech Stack:** Rust stable, Horizon native hooks 411, horizon-mixins, Python packaging.
**Spec:** docs/superpowers/specs/2026-11-13-hypixel-design.md

## Global Constraints
- Target Minecraft 26.3 and Horizon 9f42064c11efe7ef3e5ed2baad7ddc2a3b36eea0; native hook API >=411.
- No fabricated stats; no live API requests or automated gameplay.
- All game commands must result from an explicit user key/command.
- Bound untrusted text/state; reset on disconnect; mod-off is inert.
- Persian installation guide; sources and checks included.

## Review Focus
- Legacy formatting and split team prefixes must not corrupt scoreboard numbers.
- Player chat must not spoof system alerts or change the active mode.
- Disconnect and lobby transitions must clear stale SkyBlock readings.
- Malformed and oversize numbers/timer commands must not panic or overflow.
- Waypoints and reminders must survive settings reload without leaking across unrelated areas.
